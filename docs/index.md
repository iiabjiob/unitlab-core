# User Guide

This is a practical guide to everyday system operations in plain language.

## Who this guide is for

- Operators who control signals and switchgear.
- Engineers who configure channels and instructions.
- New users who need to start quickly.

## Quick entry by role

### I am an Operator

1. Start with [Getting Started](/guide/quick-start).
2. Open [Switchgear](/guide/switchgears) for command and feedback operations.
3. Use [Troubleshooting](/guide/troubleshooting) when command/state confirmation fails.

### I am an Engineer

1. Start with [Signals](/guide/signals) to import and allocate signal lists.
2. Continue with [Instructions (Sequences)](/guide/sequences) to build repeatable procedures.
3. Keep [Interface](/guide/interface) open for cross-module navigation.

### I need incident recovery now

1. Open [Troubleshooting](/guide/troubleshooting).
2. If needed, use [FAQ](/guide/faq) for quick decision paths.

## Standard learning path

1. Open [Getting Started](/guide/quick-start).
2. Read [Interface](/guide/interface).
3. Go to the module you need:
   - [Signals](/guide/signals)
   - [Switchgear](/guide/switchgears)
   - [Instructions (Sequences)](/guide/sequences)

## Important

If you are unsure about an action, check [Troubleshooting](/guide/troubleshooting) or [FAQ](/guide/faq) first.
